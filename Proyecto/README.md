# 🧁 Ríos Pastries

Sistema Web para la Gestión de Pedidos y Eventos

## 🛠 Tecnologías

- **API**: Python + FastAPI
- **Web**: HTML + Django
- **Móvil**: Flutter
- **Base de datos**: MySQL (XAMPP)

## 📦 Instalación

### Base de datos
1. Inicia XAMPP (Apache + MySQL)
2. Abre phpMyAdmin: http://localhost/phpmyadmin
3. Importa `database/schema.sql`

### API (FastAPI)
```bash
cd api
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
